# 📝 My Text Editor – Python Notepad

## 📌 Project Overview
My Text Editor is a simple desktop-based text editor application developed using Python and Tkinter. It works like a basic Notepad application and allows users to create, open, edit, and save text files through a user-friendly graphical interface.

This project demonstrates the use of Python GUI programming and file handling.

## ✨ Features

- **New File:** Clear the text area to start writing a new document.
- **Open File:** Open and read existing `.txt` files.
- **Save File:** Save written content into a text file.
- **Exit:** Close the application using the File menu.
- **User-Friendly Interface:** Simple graphical interface with a text editing area.
- **File Menu:** Easy access to New, Open, Save, and Exit options.

## 🛠️ Technologies Used

- Python
- Tkinter (GUI Library)
- File Handling
- Messagebox
- Filedialog

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Open the project folder**

```bash
cd My-Text-Editor
```

**3. Run the application**

```bash
python notepad.py
```

Note: Python 3 should be installed on your computer. Tkinter is generally included with standard Python installations.

## 🚀 How to Use

1. Run the Python file.
2. The Text Editor window will open.
3. Click on the **File** menu.
4. Select **New** to start a new document.
5. Select **Open** to open an existing text file.
6. Select **Save** to save your written content.
7. Select **Exit** to close the application.
